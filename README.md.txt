# Student Performance Prediction - Multiple Linear Regression

## Project Overview
Predicts Student Performance Index using Multiple Linear Regression with Flask Web App. Code is in OOPs and Exception Handling.

## Dataset
- File: Student_Performance.csv
- Features: Hours Studied, Previous Scores, Extracurricular Activities, Sleep Hours, Sample Question Papers Practiced
- Target: Performance Index

## How to Run
pip install -r requirements.txt
python python.py
python app.py
Open: http://127.0.0.1:5000

## Project Structure
- python.py - Model training (OOP)
- app.py - Flask App (OOP)
- templates/index.html - Webpage
- model.pkl - Saved model
- requirements.txt
- README.md
